# 🏥 Patient Healthcare Data Analysis Dashboard

A Python-based healthcare data analysis project developed using **Google Colab**. This project performs data cleaning, exploratory data analysis (EDA), and visualizes patient health records through interactive charts and graphs to gain meaningful healthcare insights.

## 📌 Project Overview
The Patient Healthcare Data Analysis Dashboard helps analyze patient medical records by:
- Cleaning and preprocessing healthcare datasets
- Removing duplicate and missing values
- Performing statistical analysis
- Grouping patient records
- Visualizing healthcare data using multiple chart types

The dashboard provides an easy way to understand patient recovery trends and medicine dosage information.
